# 逐张验收

1. 对照输入：轮廓、结构、色相、比例、Logo、标签、包装、配件；未知角度不算已验证。
2. 文案逐字看：事实有来源，单位和值一致，无伪字、虚假认证/促销；少字优先。
3. SKU：颜色和色名一致；套装逐件清点，可见件数等于文案。母版布局对照查看。
4. 场景：透视、接触阴影、真实尺度、使用合理；产品不被道具遮挡。单图不混空间。
5. 人物：none 检查手脚；faceless 检查侧脸、眼鼻口和镜面反射。
6. 文件：实际像素尺寸/比例、可解码性；透明不是白底或棋盘格。alpha 检查不能替代边缘视觉检查。
7. 状态：`generated` 表示已有图片；`accepted` 表示机器检查和视觉检查均通过；未核对平台规则则不能宣称已通过上架审核。

错字：先做仅修文案的定向编辑，保留其他元素。仍错时降低文案密度；用户需要精确排版时说明可使用排版工具，不能交付乱码后声称合格。

产品跑偏：以原商品图重新编辑，不拿错误图当唯一外观参考。失败图片不带动全套重做。

不能保证生成式编辑像素级保真；高风险结构/型号/颜色需商家实物复核。
