# MORA · 把暮色，留在身边

![主视觉](images/campaign.png)

**这是为展示 Skill 而制作的虚构商品案例。** MORA 品牌、香水包装和 50 mL 标注都是概念设定；没有真实销量、订单、功效或商业合作。

## 模拟收到的需求

> 我想做一个有记忆点的香水系列。瓶身是深墨绿玻璃，盖子像一颗米白色小月亮。帮我做一张干净商品图、一张能当首页的暮色广告、一张设计细节页和一张窗边生活图。所有图片是同一个产品，不写未经证实的香调和留香时长。

## 创意决定

- **产品识别：** 矮圆柱瓶身、球形米白盖、黄铜颈圈、奶油白小标签。
- **视觉系统：** 墨绿、黄铜金、奶油白；用材质与光影形成变化。
- **商业主视觉：** 球形瓶盖与背景落日光晕呼应，瓶身在水面与洞石之间保持清晰。
- **设计页：** 中文信息层级简短，展示形体与光的关系。
- **生活图：** 同一瓶子进入傍晚窗边，保留一张日常场景素材。
- **一致性方法：** 先生成母图，再让后三张都引用它；没有把三个相似瓶子当同一商品。

## 如实说明效果边界

本次效果适用于虚构商品的视觉展示。瓶盖/瓶身比例、标签排版和高光会随生成发生轻微变化，不是逐像素复刻。场景道具不表示随商品附送；背景光晕是创意布景，不是香水功效。

这些图不作为真实商品材质鉴定、容量测量或真实买家评价的证据。没有进行平台审核，也没有以销量或点击率验证转化效果。
